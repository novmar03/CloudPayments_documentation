# Документация CloudPayments

Каркас документации для постепенного наполнения. Оглавление, оформление, аудитории, 46 страниц и 129 заголовков подразделов сохранены из HTML-прототипа. Тексты статей, таблицы, код, иллюстрации и ссылки внутри статей удалены. Под заголовками нет текста-заглушек.

## Открыть прототип

Откройте `index.html` в браузере. Все страницы и стили находятся в одном файле: локальный сервер и установка зависимостей не нужны. Внутренние переходы и фильтры работают без интернета.

## Добавить содержание

1. Выберите страницу в `docs/` и добавьте текст под нужным заголовком. Названия, порядок и адреса страниц сохранены.
2. Пересоберите HTML из корня проекта:

   ```sh
   python3 scripts/export-html.py
   ```

3. Проверьте внутреннюю навигацию и сохраните изменения:

   ```sh
   node scripts/check-html.cjs
   ```

`index.html` создаётся автоматически. Редактировать нужно Markdown-файлы в `docs/`, затем обновлять HTML. Экспорт поддерживает заголовки, абзацы, списки, таблицы, ссылки, изображения и блоки кода; компоненты MDX предназначены для версии Docusaurus.

## Файлы проекта

| Путь | Назначение |
| --- | --- |
| `index.html` | Готовый кликабельный прототип |
| `docs/` | Страницы в Markdown; `index.mdx` — оглавление Docusaurus |
| `src/components/navigation.json` | Группы, порядок страниц и аудитории |
| `src/offline-template.html` | Оформление и навигация HTML-прототипа |
| `scripts/export-html.py` | Сборка автономного HTML; Python 3, без сторонних пакетов |
| `sidebars.js` | Боковое меню Docusaurus |
| `src/components/DocumentationIndex.jsx` | Оглавление с фильтрами в Docusaurus |
| `src/css/custom.css` | Оформление Docusaurus |

В `navigation.json` аудитория `business` означает «Для бизнеса», `developer` — «Для разработчиков», `both` — обе аудитории. Раздел «Бизнес-сценарии оплаты» имеет значение `both`.

## Запуск Docusaurus

Исходный проект Docusaurus также сохранён. Требуется Node.js 20 или новее.

```sh
npm ci
npm start
```

Команда `npm run build` собирает сайт в `build/`. Адрес и подпапка будущей публикации задаются через `DOCS_URL` и `DOCS_BASE_URL`. Они не нужны для открытия автономного HTML.

Webpack закреплён на 5.101.3 для совместимости с Docusaurus 3.9.2. У проекта нет автоматического деплоя: размещение репозитория и публикация сайта — отдельные действия.
