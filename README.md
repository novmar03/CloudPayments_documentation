# Документация CloudPayments

Сайт документации на Docusaurus и автономная HTML-версия. Содержимое поддерживается в Markdown и через отдельный no-code редактор.

## Структура проекта

| Путь | Назначение |
| --- | --- |
| `docs/` | Страницы Markdown/MDX |
| `src/content/editor-pages.json` | Исходные публикации редактора: документ и HTML-сегменты |
| `src/components/navigation.json` | Группы, порядок страниц и аудитории |
| `src/components/` | Компоненты страниц и отображение публикаций редактора |
| `src/css/` | Стили документации |
| `src/offline-template.html` | Шаблон автономной версии |
| `plugins/` | Поиск и подготовка данных редактора при сборке |
| `scripts/` | HTML-экспорт, проверки и обработка данных |
| `tests/` | Проверки сохранности текста и изображений |
| `sidebars.js` | Боковое меню Docusaurus |
| `index.html` | Автономная версия и источник для подключения редактора |
| `static/img/editor/` | Изображения редактора с именами по SHA-256 содержимого |

## Работа с содержимым

Обычные страницы редактируются в `docs/`. Страницы, опубликованные редактором, используют HTML-сегменты из `src/content/editor-pages.json` через компонент `EditedSection`. Для них следует править содержимое в редакторе: изменение только Markdown не заменяет опубликованные сегменты.

Порядок и группы задаются в `navigation.json` и боковом меню; менеджер страниц редактора синхронизирует структуру при публикации. Удалённые страницы могут оставаться в Markdown для сохранения входящих ссылок. Не удаляйте такие файлы как неиспользуемые без проверки ссылок.

`index.html` пересобирается командой `npm run build:html`, затем проверяется через `npm run check:html`. Он хранится в репозитории, поскольку нужен автономной версии и редактору.

Изображения редактора загружаются отдельными файлами. Для локального просмотра `index.html` сохраните рядом каталог `static/img/editor/`; одного HTML-файла для этих изображений недостаточно. Docusaurus публикует их в `img/editor/` и учитывает `DOCS_BASE_URL`. Исходники черновиков сохраняются в репозитории редактора. Файлы изображений автоматически не удаляются.

## Сборка и проверки

Требуется Node.js 20 или новее.

```sh
npm ci
npm test
npm run build
npm start
```

Готовый сайт находится в `build/`. Для размещения в подпапке задайте `DOCS_URL` и `DOCS_BASE_URL`, например `/CloudPayments_documentation/`. Workflow в `.github/workflows/` отвечает за автоматическую публикацию; локальная сборка сама ничего не публикует.

## Данные редактора в сборке

Импорт `editor-pages.json?render` проходит через `plugins/editor-render-data.cjs`. Loader оставляет только HTML-сегменты. Для старых публикаций со встроенными PNG/JPEG/GIF/WebP он сохраняет совместимость: извлекает их в `build/assets/editor-media/` и объединяет одинаковые изображения по хэшу. Новые публикации сразу используют файлы из `static/img/editor/`.

Перенос старых встроенных изображений выполняется командой `node scripts/migrate-editor-images.cjs`. Дополнительный аргумент — путь к локальному репозиторию редактора — позволяет также сохранить все файлы `editor-assets` из `origin/documentation-drafts`, включая неиспользуемые. Команда не изменяет черновики. Поисковый индекс создаётся автоматически. Каталоги `build/`, `.docusaurus/` и `node_modules/` не нужно коммитить.

При изменении `src/components/EditedSection.jsx` проверяйте совместимость с `lib/publish.ts` в репозитории редактора: публикация сохраняет существующий компонент и при необходимости добавляет обработку путей изображений.


## Языковые версии

Глобус слева от поиска переключает русский и английский язык, сохраняя страницу и якорь. В HTML-версии английские адреса имеют вид `#/en/tech/api`, в сборке Docusaurus — `/en/tech/api/`.

Переводы автор публикует вручную из редактора. Они хранятся в `src/content/editor-pages.en.json` и в `i18n/en/docusaurus-plugin-content-docs/current/`. Русские страницы остаются отдельными. Пока перевода нет, читатель видит уведомление и ссылку на русскую версию. Английский поиск ищет только в опубликованных английских страницах.
