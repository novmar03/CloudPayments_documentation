# Документация CloudPayments

Сайт документации на Docusaurus и автономная HTML-версия. Содержимое поддерживается в Markdown и через отдельный no-code редактор.

## Структура проекта

| Путь | Назначение |
| --- | --- |
| `docs/` | Страницы Markdown/MDX |
| `src/content/editor-pages.json` | Исходные публикации редактора: документ и HTML-сегменты |
| `src/components/navigation.json` | Группы, порядок страниц и аудитории |
| `src/components/` | Компоненты страниц и отображение публикаций редактора |
| `src/css/` | Стили документации |
| `src/offline-template.html` | Шаблон автономной версии |
| `plugins/` | Поиск и подготовка данных редактора при сборке |
| `scripts/` | HTML-экспорт, проверки и обработка данных |
| `tests/` | Проверки сохранности текста и изображений |
| `sidebars.js` | Боковое меню Docusaurus |
| `index.html` | Автономная версия и источник для подключения редактора |

## Работа с содержимым

Обычные страницы редактируются в `docs/`. Страницы, опубликованные редактором, используют HTML-сегменты из `src/content/editor-pages.json` через компонент `EditedSection`. Для них следует править содержимое в редакторе: изменение только Markdown не заменяет опубликованные сегменты.

Порядок и группы задаются в `navigation.json` и боковом меню; менеджер страниц редактора синхронизирует структуру при публикации. Удалённые страницы могут оставаться в Markdown для сохранения входящих ссылок. Не удаляйте такие файлы как неиспользуемые без проверки ссылок.

`index.html` пересобирается командой `npm run build:html`, затем проверяется через `npm run check:html`. Он хранится в репозитории, поскольку нужен автономной версии и редактору.

## Сборка и проверки

Требуется Node.js 20 или новее.

```sh
npm ci
npm test
npm run build
npm start
```

Готовый сайт находится в `build/`. Для размещения в подпапке задайте `DOCS_URL` и `DOCS_BASE_URL`, например `/CloudPayments_documentation/`. Workflow в `.github/workflows/` отвечает за автоматическую публикацию; локальная сборка сама ничего не публикует.

## Данные редактора в сборке

Импорт `editor-pages.json?render` проходит через `plugins/editor-render-data.cjs`. Loader оставляет только HTML-сегменты, извлекает встроенные PNG/JPEG/GIF/WebP в `build/assets/editor-media/` и объединяет одинаковые изображения по хэшу. Исходный JSON не изменяется; изображения сохраняют исходные байты и формат.

Это уменьшает объём данных в JavaScript, но не уменьшает исходный JSON, отправляемый редактором в GitHub. Поисковый индекс создаётся автоматически. Каталоги `build/`, `.docusaurus/` и `node_modules/` не нужно коммитить.

При изменении `src/components/EditedSection.jsx` синхронизируйте его шаблон `lib/github/templates/EditedSection.jsx.txt` в репозитории редактора: он используется при публикации страниц.
