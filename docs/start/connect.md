### Этапы подключения

## Интернет-эквайринг CloudPayments

Это сервис для приема онлайн-платежей банковскими картами, с помощью альтернативных Pay-методов без ввода данных карты, а также в рассрочку и Долями. CloudPayments позволяет безопасно принимать оплату на сайте, в приложении или в социальных сетях через ссылки.

### Зачем подключать CloudPayments

Чтобы упростить процесс оплаты для клиентов, увеличить количество завершенных покупок и расширить выбор методов оплаты.
